Beslutningspunkter i denne demo

Return context Tilbage-link øverst bevarer brugerens navigation state.
Header Titel, metadata, badges og 1–3 primære handlinger.
Tabs Stabile undersektioner som Overblik, Bede, Filer og Medlemmer.
Summary cards 3–5 vigtigste nøgletal eller statusser.
Related sections Viser nok til overblik og linker videre til fuld sektion.
Danger zone Arkivering og sletning er adskilt fra almindelige handlinger.
