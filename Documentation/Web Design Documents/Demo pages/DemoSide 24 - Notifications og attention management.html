Attention matrix

Aktiv have Almindelig objektstatus. Level 0 · badge
Thumbnail oprettes Systemet arbejder, men det er ikke en fejl. Level 1 · object
Invitation afventer Relevant status, der kan kræve opfølgning. Level 2 · section
Fil udløber snart Brugeren bør kunne handle, fx gøre filen permanent. Level 2 · inline
Upload fejlede Handling mislykkedes og kræver forklaring/retry. Level 3 · inline
Betaling kræver handling Påvirker adgang/funktioner på tværs af appen. Level 3 · banner

Beslutningspunkter

  • Attention skal være sparsom: Ikke alle statusser er notifications.
  • Attention skal være forklarende: Teksten skal fortælle, hvad der sker og hvorfor.
  • Attention skal være handlingsorienteret: Hvis brugeren kan gøre noget, skal næste handling være tydelig.
  • Attention skal være kontekstuel: Vis beskeden tæt på årsagen.
  • Attention må ikke skjules: Collapsed sections skal stadig vise status i headeren.
  • Rød og orange skal bruges sparsomt: Ellers mister farverne betydning.
