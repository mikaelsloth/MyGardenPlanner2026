Komponentnavngivning og design tokens

Denne demo samler designguiden i en komponentordbog og et token-system. Komponentnavne beskriver formål frem for udseende, og tokens beskriver designbeslutninger frem for tilfældige værdier.

Variants og states

variants

Variants beskriver intention

Brug warning, danger og restricted frem for farvenavne som orange eller rød.

neutral primary warning danger
states

States beskriver tilstand

State er ikke det samme som variant. State er komponentens aktuelle tilstand.

loading selected expanded collapsed archived processing

Token taxonomy

global tokens

Global

Rå fundamentværdier som farveskala, spacing-skala og fontfamilier. 

--color-green-600
--space-4
--radius-3
semantic tokens

Semantic

Betydning i UI’et. Det er disse tokens komponenter primært bør bruge. 

--mgp-color-primary
--mgp-color-bg
--mgp-color-text-muted
component tokens

Component

Komponentspecifikke beslutninger for padding, radius, fokus og tæthed. 

--mgp-density-card-padding
--mgp-touch-target-min
--mgp-focus-ring-color

Token eksempler

--mgp-color-primary Primær handling og brand
--mgp-color-surface-muted Dæmpede flader og badges
--mgp-color-warning-bg Attention level 2
--mgp-color-danger-soft Danger og fejlbaggrund

Component spec card

component documentation template

StatusMessage

Formål Viser inline feedback tæt på årsagen.
Brug når En handling lykkes, fejler, kræver opmærksomhed eller forklarer en tilstand.
Brug ikke når Beskeden er en kort, ikke-kritisk bekræftelse som “Link kopieret”. Brug toast i stedet.
Variants success, info, warning, danger, processing, restricted
States default, loading, dismissed
Accessibility Skal have tekst. Farve og ikon er supplement. role="alert" bruges kun ved vigtige fejl.
Mobile Fuld bredde. Handlinger stackes.
Print Vises kun, hvis beskeden er relevant for dokumentation.

Beslutningstabel

Navngivning Komponentnavne beskriver formål, ikke udseende. StatusMessage
Komponentniveau Primitives, patterns og domain components holdes adskilt. 3 niveauer
Variants Variants beskriver intention, fx warning, danger, restricted. Intention
States States beskriver aktuel tilstand, fx loading, archived, processing. Tilstand
Tokens Tokens opdeles i global, semantic og component tokens. Token taxonomy
Accessibility Focus ring og touch target er tokens, ikke tilfældige værdier. Baseline
Density Density styres via token overrides, ikke separate komponentkopier. Token override
