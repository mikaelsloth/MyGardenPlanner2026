Nordisk havearkitekt · demo 7

Responsiv navigation

Denne demo viser desktop sidebar, valgfri collapsed sidebar/nav rail og mobil/tablet off-canvas drawer. Collapse er et brugervalg, som senere kan gemmes i brugerens browser.

designbeslutning

Expanded er standard

Collapsed sidebar er en valgfri desktop-tilstand til indholdstunge sider, ikke en automatisk side-for-side opførsel.

Navigationstilstande

De tre tilstande vi designer efter.

desktop default

Expanded sidebar

Standardtilstand på desktop. Giver bedst overblik og kræver ikke ikonforståelse.

desktop optional

Collapsed sidebar

Brugervalg til tunge sider. Viser ikon-rail, active state, dots/badges og hover-labels.

tablet / mobil

Off-canvas drawer

Topbar med menu-knap. Drawer indeholder samme navigation som desktop-sidebar.
