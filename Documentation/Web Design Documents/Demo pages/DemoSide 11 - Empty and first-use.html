Empty states og first-use states

Denne demo viser, hvordan tomme tilstande kan hjælpe brugeren videre: første oprettelse, tomme sektioner, tomme filtre, søgninger uden resultat, manglende adgang, fejl og loading.

hovedregel

Tom tilstand er også design

Empty states skal forklare hvad der mangler, hvorfor det er relevant, og hvad brugeren kan gøre nu.

Loading før empty

loading / skeleton
