Loading states og skeletons

Denne demo viser loading-principper for MyGardenPlanner: skeletons til indhold, loading buttons til handlinger, progress bars til målbar fremdrift og forklarende states, når noget tager længere tid end forventet.

hovedregel

Spinner til handlinger, skeleton til indhold

Brugeren skal se, at appen arbejder — men loading må ikke blokere mere end nødvendigt.

Dashboard skeleton

Summary cards kan loade lokalt, mens resten af siden allerede er synlig.

Card skeletons

Compact row skeletons

Bruges til lange lister, hvor endelig visning er kompakte rækker.

Media skeletons

Metadata kan vises før thumbnails; thumbnail-loader må ikke blokere filkortet.
