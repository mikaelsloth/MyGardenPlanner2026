Billeder og dokumenter

Denne demo viser principper for upload, thumbnails, preview, fuld størrelse, download, restriktioner og performance. Hovedideen er: metadata og thumbnails først, preview ved aktiv handling, original/download kun ved eksplicit handling.

designprincip

Originalfilen hentes ikke automatisk

Lister viser kun metadata og thumbnails. Preview og download kræver aktiv brugerhandling.

Performance-principper

Performance er et UI-krav, ikke kun et teknisk krav.

thumbnail-kontrakt

Small / Medium / Large

  • Small

    Compact rows og små lister.

  • Medium

    Media cards og thumbnail grids.

  • Large

    Preview panel, ikke standardliste.

load-regler

Hent kun det nødvendige

  • Metadata først

    Filnavn, content type, ejer, status og størrelse kan vises uden originalfil.

  • Lazy thumbnails

    Thumbnails uden for viewport bør ikke hentes før de skal bruges.

  • Original kun eksplicit

    Originalfilen hentes ved “Åbn fuld størrelse” eller “Download”.
