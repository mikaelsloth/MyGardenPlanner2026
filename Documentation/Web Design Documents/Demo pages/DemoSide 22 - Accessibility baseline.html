Accessibility baseline

Denne demo viser en praktisk accessibility baseline for MyGardenPlanner: skip link, semantisk HTML, synlige labels, focus states, icon-only labels, tekstlige statusbeskeder, keyboard-friendly drawers/modals, tables, alt-tekster og reduced motion-regler.

semantic html

Semantik først

Brug rigtige elementer: knapper som buttons, links som links, tabeller som tables og sektioner med headings.

focus

Tydeligt fokus

Alle interaktive elementer har en synlig :focus-visible state. Tab rundt i demoen for at se det.

color + text

Farve står ikke alene

Badges, status og fejl har altid tekst — ikke kun farve eller ikon.

Synlige labels og field-level validation

form

Redigér haveoplysninger

Baseline checklist

Generelt

  • Semantisk struktur
  • Logiske headings
  • Tydelige knap- og linklabels
  • Synlig focus state
  • Farve står ikke alene

Forms og feedback

  • Synlige labels
  • Fejl ved feltet
  • Tekstlige statusbeskeder
  • Disabled states forklares ved behov
  • Upload kan bruges uden drag/drop

Overlays og media

  • Dialog/drawer har titel
  • Tydelig lukkevej
  • Fokusstyring i implementation
  • Informative billeder har alt-tekst
  • Preview kan lukkes med tastatur
