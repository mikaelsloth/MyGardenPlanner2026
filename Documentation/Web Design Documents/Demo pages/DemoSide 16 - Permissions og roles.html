Permissions og roles i UI

Denne demo viser, hvordan samme have kan opleves som ejer, redaktør, læser og restricted bruger. Fokus er på at skelne mellem synlige handlinger, skjulte handlinger, disabled handlinger med forklaring og no-access states.

Backend beskytter — UI forklarer

Brugeren skal kun se relevante handlinger. Når en handling er forventet, men ikke tilladt, kan UI’et forklare hvorfor.
