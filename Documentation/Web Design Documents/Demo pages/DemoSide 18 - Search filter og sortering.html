Search, filter og sortering

Denne demo viser filterbar, aktive filterchips, sortering, view-mode, mobile filter drawer, filtered empty state og URL-state-principper. Mønsteret skal kunne genbruges på planter, materialer, haver, filer og invitationer.

hovedregel

Søgning finder. Filter indsnævrer. Sortering prioriterer.

View-mode ændrer kun præsentationen og bør ikke blandes sammen med filter.

URL-state og return-flow

Search, filter, sortering, pagination og view-mode bør kunne genskabes via URL.

URL-state

Eksempel: planteliste

/planter?search=lavendel&lys=sol&type=staude&sort=name-asc&view=compact&page=1

Denne state kan bruges ved refresh, back/forward og return-flow efter oprettelse.

return-flow

Efter oprettelse

Hvis den nye plante ikke matcher filtrene, forklarer UI’et hvorfor.

i

Planten er oprettet

Den vises ikke i listen, fordi det aktive filter er “Sol”.

Pagination

Når søgning eller filter ændres, bør pagination nulstilles til første side.

Eksempel: Filter ændres → page resettes til 1 for at undgå tomme sider.
