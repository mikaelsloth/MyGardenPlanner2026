Arkivering vs. sletning

Denne demo viser forskellen på at arkivere, gendanne, fjerne relationer og slette data. Arkivering holder historik og dokumentation intakt, mens sletning er en destruktiv handling.

hovedregel

Arkivér før slet

Hvis objektet kan have historisk værdi, bør det arkiveres frem for at blive slettet.

Begreber

Ordene skal bruges konsekvent i hele appen.

Begreb Betydning Eksempel Typisk UI
Arkivér Skjul fra aktive visninger, men bevar data. Arkivér have Confirmation + badge + filter
Gendan Flyt arkiveret objekt tilbage til aktiv visning. Gendan bed Gendan-knap + status
Fjern Fjern relation, men bevar objektet. Fjern plante fra bed Inline confirmation / undo
Slet Fjern data eller gør data utilgængelig. Slet fil Danger confirmation
